# rust-agents-gitops

The GitOps version of [rust-agents](https://github.com/gbaeke/rust-agents): the same Rust agent, MCP server, Postgres and agentgateway, on the same kind setup, but [Argo CD](https://argo-cd.readthedocs.io/) applies everything from git instead of `deploy.sh`.

The source was copied from rust-agents at commit `5a40b5f`. Since then the two repos are independent and may drift apart.

> Work in progress. See [docs/plan.md](docs/plan.md) for the phases and their status.
